**Role:** Sole developer of the iOS and Android apps. UX, UI and illustrations by my sister.

### Highlights

- Built the original iOS app with UIKit: custom components, stack views, direct manipulation of view layers and a stack data structure behind the editor.
- Meme editor based on multi-touch gestures: move, pinch to scale and rotate stickers and text, with layer ordering.
- Backed by Firebase: Database, Auth, Messaging, Storage, Analytics and Crashlytics.
- Started a 2025 rewrite of the iOS app in SwiftUI, moving local storage to SwiftData and adding Google sign-in.

### Android

- Android version with its own touch system for gesture-based editing of stickers and text.
- Migrated the codebase from Java to Kotlin, moved the camera to CameraX and added Android 15 support (16 KB page size).
- Stickers are served from Firestore with a local offline fallback and image caching.

### Backend

- Wrote a Firebase Function in Python that checks uploaded images with an NSFW filter before they are shared.

### Tech

Swift, UIKit, SwiftUI, SwiftData, Kingfisher, SDWebImage, Kotlin, CameraX, Firebase (Auth, Firestore, Storage, Messaging, Functions, Crashlytics), Python
